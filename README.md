# LLM-lab-1

Лабараторная работа №1 по промпт-инженерии студента Ynelo

##Структура проекта:##
/output - папка для хранения выводов ответов моделей
.env - переменные окружения. Используються 2 переменные: API_KEY и PATH_OUTPUT
.gitignore - итак ясно
prompt.txt - текстовый файл с текстом, который будет использоваться в проекте
get_model_list.py - код для получения списка доступных моделей. Задание №1
model_test.py - код для отправки первого тестового запроса. Задание №1
testing_models.py - код для отправки первого тестового промпта. Задание №2
prompts-to-models.py - код для отправки запросов на суммаризацию текста. Задание №3
prompt_Q&A.py - код для отправки запросов для вопрос-ответ. Задание №4
prompt_with_forms.py - код для запросов с разными формами ответа. Задание №5
prompt-of-gal.py - код для запросов с поиском галюцинаций. Задание №6
metrics_answers.py - код для добавления к csv отчетам метрики
